# HyperNet Relay Chat

HyperNet Relay Chat (HRC) is a planned Rust chat application for HyperNet, with a
graphical interface, terminal interface, command-line tools and an agent API.

The project is in design. There is no application implementation or installable
release. HyperNet transport, explicit agent delegation and two-network federation
are required product capabilities.

Product documentation is maintained with the source. Design changes use branches
and pull requests. Release support and security properties will be stated only
after the corresponding integration and qualification work passes.

This repository is private. No software licence has been selected.
